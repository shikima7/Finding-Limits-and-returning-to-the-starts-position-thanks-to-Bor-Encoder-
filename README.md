# Finding-Limits-and-returning-to-the-starts-position-thanks-to-Bor-Encoder-
Using an bor encoder, it is possible to set a limit on the number of rotations, and when the limit is reached, it returns to the initial position.

This project focuses on robotics control systems for FTC (FIRST Tech Challenge) robots using Bor Encoder integration, adaptive RPM calculations, and coordinate-based positioning.

The system is designed to calculate RPM values, manage turret rotation limits, reset coordinate positions, and support adaptive shooting from different locations on the field.

The main goal of this project is to improve robot accuracy, automation, and movement control during the DECODE season.

---

## Features

- Bor Encoder integration for movement tracking
- Finding movement limits and returning to the starting position
- Resetting X and Y coordinate values
- Adaptive shooting from any robot position
- RPM calculation for motors
- Fully functional DriveTrain code
- Turret rotation limit calculation
- Coordinate-based robot positioning
- Integration with PedroPathing

---

## Purpose

This project was created for FTC robotics competitions and provides a complete base system for robot movement and targeting.

The system allows the robot to:
- Automatically calculate RPM values
- Control turret rotation safely within limits
- Return to the initial position after reaching movement limits
- Reset location coordinates when needed
- Perform adaptive shooting from different field positions

This code can be used as a foundation for:
- Autonomous navigation
- Shooting systems
- Position tracking
- DriveTrain control
- FTC Decode season robots
